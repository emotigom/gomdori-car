# 곰도리 — 대시보드 결과 정리

## 누가, 언제 보나

호주 자동차 애프터마켓(부품 온라인 판매) 가게의 **마케팅 담당자**가 **주간 콘텐츠 기획 회의 전**에 보는 대시보드.
"이번 주에 어떤 부품을 SNS 콘텐츠로 밀어도 되는가, 어떤 차종 고객을 겨냥할 것인가"를 정하는 데 쓴다.
화면 가운데에 고객이 많이 묻는 차량(기본값 Toyota HiLux 2018)이 3D로 떠 있고, 마우스를 올리면 X-RAY로 바뀌며 13개 부품 계통이 실제 적용 부품 목록과 선으로 연결된다.

## KPI (상단 자원 바, 왼쪽부터)

1. **총 부품 수** — 60,000개 (Pages 데모 기준. 서버 모드는 1,000,000개)
2. **내 차 적용 부품 수** — 선택한 차량에 맞는 부품 1,006개
3. **콘텐츠 준비 부품 수** — 판매중 · 근거 A등급 · 이미지 권리 확인을 모두 만족해 바로 홍보해도 되는 부품 8,536개 (14.2%)
4. **HOLD 부품 수** — 규격 충돌 등으로 홍보를 막아 둔 부품 2,409개

## 차트

- **격납고(3D)**: 계통별 적용 부품 수 막대 13개 + 리더 라인 카드(계통 코드 · 적용 수 · 대표 부품 2개)
- **분석 › 카탈로그 전력**: 카테고리별 부품 수 막대, 브랜드 상위 15 막대, 계통별 카탈로그 규모 막대
- **분석 › 내 차 적용**: 13계통 레이더(다른 차량과 겹쳐 비교) + 계통별 적용 부품 막대
- **분석 › 품질 게이트**: 콘텐츠 준비 비율 게이지, 근거 등급·자산 권리·판매 상태 도넛 3개, 게이트를 막는 요인 막대
- **분석 › 시장 신호**: 플랫폼·형식별 반응 중앙값 컬럼(가상 예시 데이터)
- **콘텐츠**: 아이디어 → 제작 검수 → 게시 승인 → 게시됨 → 학습 평가 칸반 + 채널별 시간당 적격 문의 막대

## 한 줄 인사이트

- 홍보 가능한 부품은 전체의 **14.2%**뿐이고, 가장 큰 병목은 광고 예산이 아니라 **근거 등급 A 미달(38.8K)과 이미지 권리 미확인(32.9K)** 이다 → 콘텐츠를 늘리기 전에 근거·권리 정리부터.
- HiLux 2018에서는 **필터 계통 적용 부품(145)이 와이퍼(38)의 3.8배** → 이 차종 고객 대상 첫 콘텐츠는 "필터 고르는 법"이 유리하다.
